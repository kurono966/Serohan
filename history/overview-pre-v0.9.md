# セロハン語（Serohan）設計概要 Ver.0.5

## 概要

**セロハン語（Serohan）**は、人工言語「セロ語」から分離・発展した姉妹言語である。

セロ語の語彙や世界観を受け継ぎながらも、**ハングルの構造を前提として一から再設計された独立言語**である。

単なるハングル表記版ではなく、「ハングルだからこそ成立する文法」を目指して設計されている。

---

# 設計理念

セロハン語は以下の思想を持つ。

* ハングルを最大限活用する
* 一文字あたりの情報量を高める
* 規則性を最優先する
* 例外を極力排除する
* ミニマルな文法を目指す
* 語順を積極的に文法要素として利用する
* 必要最低限のみ助詞・助辞を用いる

---

# 文字体系

使用文字は現代ハングル。

韓国語の発音規則（連音化・終声中和など）は採用せず、**表記どおりに読む**。

---

# 母音

基本母音は5つ。辞書では派生母音ㅑ・ㅛ・ㅠも採用する。ㅘ・ㅝ・ㅟ・ㅞは意味領域のみを予約しており、語根は未割り当て。

| 母音 | 発音  |
| -- | --- |
| ㅏ  | /a/ |
| ㅔ  | /e/ |
| ㅣ  | /i/ |
| ㅗ  | /o/ |
| ㅜ  | /u/ |

日本語話者にも発音しやすい体系とし、ㅓ・ㅡは採用しない。ㅝは独立した /wo/ として予約し、ㅓ単独の採用を意味しない。

---

# 語根

すべての語根は

> **CV（初声＋母音。初声ㅇは無音）**

で構成される。

語根は**品詞を持たず、「概念」そのもの**を表す。

例

* 메　愛
* 에　海
* 아　山
* 오　木
* 나　私

※Ver.0.2までは「아＝森」としていたが、dictionary.md（正式な語根辞書）では「아＝山」「요＝森」と定義されているため、Ver.0.3でdictionary.mdに合わせて修正した。

---

# 終声（パッチム）

終声は

> **概念をどのような役割で用いるか**

を表す。

終声は助詞ではなく、**語そのものの性質を決定する**。

## 単パッチム

| 終声 | 意味      |
| -- | ------- |
| ∅  | 概念      |
| ㄱ  | 行為（動詞）  |
| ㄹ  | 属性（形容詞） |
| ㅂ  | 修飾      |
| ㅁ  | 実体（個体化） |

### 実体（ㅁ）

∅（無終声）が表すのは、その語根が指す領域全体を包括する**抽象的な概念**である。

一方ㅁは、その概念を

> **具体的・物理的な一個の実体として切り出したもの**

を表す。「名詞化」というよりは**個体化（インスタンス化）**に近い機能であり、名詞語根に限らずどの分野の語根にも適用できる。

例

* 오　木（という概念・木性）　→　옴　（目の前の）一本の木
* 카　大きい（という性質）　→　캄　大きいもの・大物
* 레　作成（という行為）　→　렘　作られたもの・作品

#### 人称代名詞における実体（ㅁ）

人称代名詞（나・네など）も同じ原理に従う。

* **∅（無終声）** → その人の**心・人格**を指す
* **ㅁ（実体）** → その人の**肉体・身体**を指す

例

* 나　私（心・人格としての私）
* 남　私の体（肉体としての私）

この対立により、たとえば「傷つける」のような動詞の目的語をどちらにするかで、

* 남を傷つける　→　身体的に傷つける
* 나を傷つける　→　心を傷つける

という意味の切り分けが可能になる。これは終声ㅁが**「概念⇄実体」という単一の一貫したルールから自然に導かれる**副産物であり、人称代名詞のための特別な例外規定ではない。

### 修飾（ㅂ）

修飾は従来の副詞より広い概念であり、

* 方法
* 様態
* 時間
* 場所
* 程度

などを包括する。

例

* 멥　愛をもって
* 엡　海のように
* 압　山に関して

※「海で」「山へ」のような格関係は表さず、概念を修飾的に扱う語となる。

---

# ダブルパッチム

ダブルパッチムは

> **動詞（ㄱ）にのみ付与できる。**

単語の活用を表す。

## 現在予定している役割

### 時制

* 過去
* 未来

### 法（モダリティ）

* 願望
* 義務
* 推量
* 否定

### アスペクト

* 完了
* 継続
* 結果状態

現行案の割り当ては [verb-inflection.md](verb-inflection.md) にまとめる。初版では一語につき一種類とし、時制・否定・相の重ね合わせは未定とする。

---

# 文法

基本語順は

> **SVO**

を採用する。

語順そのものを重要な文法要素として利用し、助詞への依存を減らす。

---

# 助詞・助辞

助詞は終声では表さない。

終声は語形成専用とし、

語と語の関係は**独立したㅎ系列CV助詞**で表現する。採用済みの5語と予約語を [particles.md](particles.md) で区別する。

対象となる文法関係は、

* ～へ
* ～から
* ～で
* ～の
* ～と

など。

これにより

* 終声＝語の内部変化
* 助詞＝語同士の関係

という役割分担を明確にする。

---

# 語彙設計

語根は単なる音の割り当てではなく、

**CV自体に意味を持たせる**ことを目標としている。

最終的には

> 子音 × 母音

の組み合わせを見るだけで、

ある程度意味領域が推測できる辞書を構築する予定である。

---

# セロ語との関係

セロ語から派生した言語であるため、

既存語彙は可能な限り継承する。

初期段階では

> **セロ語の語尾子音を削除し、CVへ変換**

することを基本方針とし、

重複する語のみ再設計する。

---

# 設計思想

セロハン語は

> **「一文字＝一つの概念」**

を基本単位とする。

さらに

> **終声によって概念の役割を切り替える**

ことで、一文字の情報量を最大化する。

文法は

* 語順
* 終声
* 最小限の助詞

のみで構成される。

複雑な活用や大量の語尾変化を持たない、規則的でミニマルな人工言語を目指す。
