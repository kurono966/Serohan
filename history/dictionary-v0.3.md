# セロハン語 語根辞書 Ver.0.3

## 運用上の注意

この辞書の104語根を現行語彙とする。意味領域は記憶の手掛かりであり、個々の意味は辞書を優先する。韓国語の同じ綴りから意味を借用しない。

`네` は他者を指し、対話では「あなた」、文脈によって「その人」と解釈する。`너` は未採用。ㅎ系列は助詞専用で、語根として派生させない。

## 母音

| ハングル | ラテン | 役割      |
| :--: | :-: | ------- |
|   ㅏ  |  a  | 基本・根源   |
|   ㅔ  |  e  | 生命・主体   |
|   ㅣ  |  i  | 情報・認識   |
|   ㅗ  |  o  | 自然・環境   |
|   ㅜ  |  u  | 人工・文明   |
|   ㅑ  |  ya | 基本概念の派生 |
|   ㅛ  |  yo | 自然概念の派生 |
|   ㅠ  |  yu | 人工概念の派生 |
|   ㅘ  |  wa | 相互作用・結合・関係 |
|   ㅝ  |  wo | 変動・運動・エネルギー |
|   ㅟ  |  wi | 構造・配置・秩序 |
|   ㅞ  |  we | 組織・システム・連帯 |

ㅏ・ㅔ・ㅣ・ㅗ・ㅜ・ㅑ・ㅛ・ㅠは採用済み。ㅘ・ㅝ・ㅟ・ㅞは予約段階であり、以下の語根表にはまだ含めない。

※ ㅘはㅏ（基本）の相互作用、ㅝはㅗ（自然）の動的変化、ㅟはㅣ（認識・情報）の立体化、ㅞはㅔ（生命・主体）の組織化を表す。
